## Project Overview
Developed a full-stack accommodation booking platform using Express.js (backend) and React (frontend), integrating secure authentication and seamless property management. The platform enables users to list, discover, and book unique stays with real-time availability and booking tracking.

The backend handles user registration/login with JWT-based authentication stored in HTTP-only cookies, bcrypt password hashing, and protected routes. Property listings support multiple image uploads via file upload or URL links using Multer and image-downloader, with full CRUD operations for hosts. All places are stored in MongoDB with Mongoose ODM, featuring title, address, description, perks, check-in/out times, and max guest limits.

The platform features complete booking lifecycle management, allowing guests to select dates, specify guest counts, and confirm reservations. Each user can view their personalized booking history with populated place details. Used CORS for cross-origin requests, Cookie-parser for token management, and dotenv for environment configuration. Git with version control for code management.

Tech Stack: (MERN); Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs, React, Multer, image-downloader, CORS, Cookie-parser, dotenv, Git, Postman.
